# Programming Languages

### What programming language should I use?

The differences in performance between languages do inherently exist, but if your aptitude for learning a new language is outside your allocated time, use the language that you are most comfortable and knowledgeable about. The differences in running speed between programming languages are not negligible, however and will affect your performance (e.g., Motion Control).

Available Languages:&#x20;

* C++
* Rust
* Python
* Block Code

Most teams use C++ since it is the most supported language, with many public libraries being written for it.
